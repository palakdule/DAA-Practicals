# Practical 1 - Time and Space Complexity Analysis

## Aim

To understand the concept of algorithm complexity and analyze the time complexity and space complexity of basic programs implemented in C.

## Programs Included

### 1. Sum of All Elements of an Array
**Description:**
Reads the elements of an array and calculates their sum.

**Time Complexity:** O(n)

**Space Complexity:** O(n)

**File:** `01_sum_of_array.c`

---

### 2. Addition of Two Matrices
**Description:**
Reads two matrices of the same order and performs matrix addition.

**Time Complexity:** O(r × c)

**Space Complexity:** O(r × c)

**File:** `02_matrix_addition.c`

---

### 3. Multiplication of Two Matrices
**Description:**
Reads two matrices and performs matrix multiplication if they are compatible.

**Time Complexity:** O(r₁ × c₁ × c₂)

**Space Complexity:** O(r₁ × c₁ + r₂ × c₂ + r₁ × c₂)

**File:** `03_matrix_multiplication.c`

---

## Language Used

- C

## Learning Outcome

- Understood the concept of time and space complexity.
- Implemented basic array and matrix operations in C.
- Analyzed the efficiency of different algorithms using Big-O notation.
