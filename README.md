# 📘 DAA Practicals

A collection of **Design and Analysis of Algorithms (DAA)** practical programs implemented in **C** as part of my B.Tech Computer Science Engineering coursework.

This repository contains implementations of different algorithmic techniques including **Searching, Sorting, Divide and Conquer, Greedy Algorithms, Dynamic Programming, Graph Algorithms, and Backtracking**.

## 🧪 Post Lab

### Graph Colouring using Backtracking

Implemented the **Graph Colouring Problem** using the Backtracking technique.

The program assigns colours to the vertices of a graph such that no two adjacent vertices have the same colour.
